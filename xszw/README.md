# 像素造物

全中文图像艺术工作台。支持故障艺术、字符成像、液态纹理、自然流动与科技粒子五类实时效果。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

生产构建：`npm run build`。静态文件在 `dist/`，可部署到任意静态托管服务。

## 功能

- 中文品牌、全中文界面与 30 款风格预设。
- 图片 JPG、PNG、WebP（10MB）；视频 MP4、WebM、MPEG（100MB，需浏览器支持解码）。
- 五种实时效果（含科技粒子：光点、连线、扫描与漂浮），支持参数调整、随机灵感、重置、播放暂停、原图对比与缩放。
- 点击画布上方的尺寸按钮设置 64 至 4096 像素的宽高；支持六款常用尺寸、比例锁定、横竖切换、完整显示/居中裁切/拉伸适配，以及恢复跟随素材。
- IndexedDB 本地收藏，保存源图片画面及五类效果参数。视频收藏保存当前帧。
- PNG、JPEG、SVG、PDF、GIF、MP4 导出。SVG 嵌入位图；PDF 使用浏览器打印；动画无音轨。
- 自定义尺寸按画布原尺寸导出，并随作品收藏保存。预览最长边限制为 1200px，导出会重新按设置的尺寸渲染。
- 跟随素材模式下 GIF 最长边 520px；自定义模式下 GIF 使用画布尺寸，15fps，过大的帧缓存会显示内存提示。MP4 使用画布尺寸，宽高向上对齐偶数，15/24/30fps，编码能力取决于设备。动态导出时长 3/5/10 秒。
- 上传文件不会发送到服务器；无广告或统计脚本。
- 响应式移动端、键盘操作与无障碍标签。
