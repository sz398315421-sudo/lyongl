# ER-6 中文交互工程图

线上入口 https://lyongl.xyz/newcar/ 。本目录保存静态项目，GitHub Pages 从同一分支的 docs/newcar 发布。更新时请同步两个目录。

场景及车辆基于 https://fable-rover.vercel.app/ 的浏览器构建，界面已中文化。右侧“更换车型”可从本机导入自含材质和纹理的 GLB 文件。永久更换默认车型时，将 GLB 放在项目内，并修改 model-config.js 的相对路径、车型名称、尺寸与朝向。通用车型沿用 ER-6 的底盘仿真。

Three.js 的许可见 vendor/LICENSE，IBM Plex Mono 字体的许可见 assets/OFL.txt。
