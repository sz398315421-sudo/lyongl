# DriveScene Studio 独立副本

本项目基于 [DriveScene Studio](https://paxton0209.github.io/DriveScene-Studio/) 的公开源码和资源建立，保留原站视觉、真实 3D 场景、全部公开界面及交互。上游版本 v0.18.0，来源提交 `8ba611899e1015567355251071cb5544e0ce4c51`。

界面已本地化为简体中文，涵盖场景导航、车型、设置、导出弹窗、状态提示、无障碍标签及说明页面。模型标识、网址参数和导出的相机参数字段保持原有格式。

## 启动

安装 Node.js 后，双击本目录的 `启动网站.bat`，在浏览器打开 <http://127.0.0.1:4173>。关闭命令窗口即可停止服务。也可以在本目录执行 `npm start`。已包含可运行的预构建文件，首次使用无需安装依赖，也无需 API 密钥。

请通过 HTTP 地址访问；直接双击 index.html 无法加载 3D 资源。

## 已保留功能

| 区域 | 功能 |
| --- | --- |
| 行驶场景 | 普通道路、高架道路、交叉路口、匝道 |
| 泊车场景 | 室内停车场、室外停车场 |
| 普通道路 | 2 / 4 / 6 车道；低位 / 高位镜头 |
| 交叉路口 | 十字路口 / 丁字路口；接近路口镜头动画与重播 |
| 匝道 | 驶出 / 并入；低位 / 高位镜头 |
| 停车场 | 默认 / 抬高 / 俯视三种视角 |
| 车辆模型 | 宝马 X6、特斯拉 Model 3、宝马 iX、沃尔沃 XC90；真实模型、预览卡片和键盘操作 |
| 场景元素 | 建筑、海岸、树木、道路施工；根据场景显示可用选项 |
| 外观 | 浅色 / 深色主题、主题记忆、过渡动画 |
| 下载 | 1920 × 1080 PNG、透视套件 ZIP、相机参数 JSON、16 位深度图 PNG |
| 透视套件 | 场景图、相机参数、深度图、透视 SVG 与中文使用说明 |
| 其他 | URL 参数恢复、移动端菜单、鸣谢与授权、加载失败重试 |

普通道路、高架道路、匝道、室内停车场和室外停车场均提供「场景动画」：点击播放后，车辆沿道路或通道向前行进，相机跟随当前视角。支持暂停、继续、重播及重置，进度条显示本段 4 秒动画的播放位置。切换场景、视角或车型会重置动画；离开当前标签页或打开车辆选择与下载窗口时自动暂停。双车道存在施工封路时，车辆会在施工区前停止。

导出会暂停行驶或泊车动画，并保留当前画面，图片、深度图、相机参数与 SVG 参考保持一致。此功能提供场景预览动画，现有导出格式仍为静态图片及透视套件。

所有模型、缩略图、启动预览图及环境资源都已包含在本地。模型渲染、切换和导出在浏览器内完成。原站的统计代码只在其原域名启用，本副本不会向原站发送访问统计。

## 开发与部署

```sh
npm install
npm test
npm run build
npm run preview
```

`npm run build` 重新生成 app.bundle.js，并将部署所需资源输出到 dist/。将 dist/ 上传到支持静态文件的服务器即可；也支持子目录部署。`.gz` 模型文件必须以原始二进制文件提供，不能再添加 `Content-Encoding: gzip`，浏览器程序会自行解压。

本副本增加了跨平台 Node.js 静态服务、Windows 启动脚本、独立静态打包流程和中文说明，原有交互与视觉保持一致。
