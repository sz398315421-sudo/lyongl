# ADAS HUD

[打开 ADAS HUD](https://lyongl.xyz/adas-hud/)。

「ADAS场景」包含「3车道变道」和「直行过路口」，「HUD光毯」包含「光毯变道」。右侧可调整车道、视角、车辆及动画，也可选择「预设视角1(双焦面)」或「预设视角2(光波导)」。

「3车道变道」支持分别播放和导出「向右变道」与「路口右转」。选择右转时，预览立即显示双向路口，蓝色引导光带沿着弯道连续显示。普通道路的三车道模式下，关闭动态交通流可显示停在最左侧车道的旁车。

「直行过路口」先在直路上行驶，接近后逐渐显现路口，再沿当前车道通过路口。整段约 14 秒，可在「路口显示」中切换三车道和旁车。

「光毯变道」先直行约 5.3 秒，再向左变道，整段约 10.2 秒。开启「仅显示光毯」可单独预览光束。

桌面右侧和手机预览下方的设置区域可独立滚动。

在「引导线效果」里开启渐变后，可分别设置近端和远端的位置、颜色及不透明度。位置按画面中的光带长度计算。0% 靠近本车，100% 是光带末端。「光带起点偏移」以米为单位修改光带近端的位置。

「透明视频（WebM）」保留整段动画的 Alpha 通道，可叠加到其他画面上。导出前会验证浏览器编码是否保留透明度，建议使用 Chrome 或 Edge。

在 After Effects 中使用「透明 PNG 序列（AE）」。导出时可指定帧率及总帧数，解压 ZIP 后选择 `frames/HUD_0001.png` 并勾选 PNG 序列。通过「解释素材 → 主要」设定 ZIP 说明中记录的帧率。

在仓库根目录配置 `HMI_BUILD_PACKAGE` 指向包含 `three` 和 `esbuild` 的 `package.json`，再运行以下命令重新生成页面和渲染包：

```powershell
$env:HMI_HUD_DIRECTORY = 'adas-hud'
node scripts/build-hud-preview.mjs
```

页面与 `/adas/` 共用车型、场景资源和样式。素材来源见 [鸣谢](CREDITS.md)。

## AR箭头

从 HUD 场景列表的「AR箭头」进入路口右转、路口左转或左侧掉头。三维预览默认沿用光毯相机，黑底显示从直行到转向引导、再回到直行的过程。左右转各 7.6 秒，左侧掉头 8.75 秒。可暂停、拖动时间轴、跳转到指定阶段或沉浸预览。右下角的下载菜单提供当前帧 PNG、演示视频、透明 WebM 和 AE 透明 PNG 序列。

展开「摄像机视角」可调整水平角、俯角、距离、视野角和向前看距离。镜头参数在三个预设间共用，并保存于浏览器和应用于导出。点击「恢复光毯视角」回到默认镜头。

展开「箭头位置」可分别调整直行起点和转向队列远点。横向、纵向偏移按默认镜头的画面宽高计算，远近偏移按米计算，正值推远，负值拉近。队列以最远箭头为画面定位基准，推远时箭头和间距一起缩小，拉近时一起放大。设置按预设分别保存在浏览器中，并应用到预览及导出。

路线的关键帧和时间轴定义在 `ar-arrow-motion.mjs`。当前网格和材质来自参考图版 `AR蓝色折面_参考图.blend`，包含独立的浅蓝前缘斜面、双翼折面及钴蓝尾壁。更新箭头时可独立重导模型，GLB 使用 Y 向上、−Z 朝前，原点作为动画锚点。导出脚本会把 UV 材质转为 GLB 内嵌纹理。

```powershell
blender -b -Y --python-exit-code 1 --python scripts/model-hud-ar-arrow.py -- 'AR蓝色折面_参考图.blend'
blender -b -Y 'AR蓝色折面_参考图.blend' --python-exit-code 1 --python scripts/export-hud-ar-arrow.py -- docs/adas-hud/assets/ar-arrow/arrow.glb
node scripts/build-hud-arrow.mjs
```
