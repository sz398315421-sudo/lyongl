# 星际外勤 MVP

竖屏、单手移动、全自动战斗的像素风微信小游戏原型。浏览器试玩版与微信小游戏入口共享同一套游戏核心。

## 当前实现

- 总部、随机任务简报、局内战斗、升级三选一、撤离和结算完整闭环
- 枪械师、战士、机械师三名具名宇航员
- 每职业 12 张专属升级卡与 3 个公开组合进化
- 锈蚀荒原、孢子沼泽、低重力月面三种生态，敌人按生态替换
- 摧毁巢穴、激活信标、守护钻机三种任务
- 低重力、陨石雨、孢子爆发、能源潮汐四种异常
- 可选精英、战利品风险、保底工资与撤离奖金
- 五种三级飞船模块、本地存档与角色解锁
- 总部五栏文字导航：档案、活动、派遣、任务、升级
- 7 日签到、每日任务和活跃度阶段奖励，均使用本地持久化
- 浏览器 WebAudio / 微信 WebAudio 程序化 8-bit 音效与循环背景音乐

## 浏览器试玩

直接打开 `index.html` 即可。若浏览器限制本地脚本，可使用任意静态文件服务器以本目录为根目录启动。

操作方式：

- 摇杆默认位于屏幕底部正中；也可按住游戏画面任意位置拖动宇航员
- 攻击和技能全部自动触发
- 升级时点击三张职业卡之一
- 完成主任务后返回撤离点，坚持上传 30 秒

浏览器存档写入 `localStorage` 的 `star-duty-save`。

## 微信开发者工具

1. 打开微信开发者工具并导入当前目录。
2. 项目类型选择“小游戏”。
3. `project.config.json` 默认使用游客 AppID；正式调试时替换为自己的小游戏 AppID。
4. `game.json` 已将 `assets/game/` 配置为普通分包 `runtime_assets`；启动时会先下载分包，再加载图片和字体。
5. 使用竖屏设备模拟器运行，首次冷启动可看到资源分包加载进度。

### 分包上传检查

- 在开发者工具中先点击“编译”，打开“详情/代码包大小分析”，确认主包不超过 4 MiB，主包与分包总和不超过 20 MiB。
- 确认分析结果中出现 `runtime_assets`，且其中包含 `assets/game`。
- 清除缓存后执行一次冷启动，再点击“预览”进行真机测试。
- 依次检查总部、档案、三颗星球、升级、战斗、撤离和结算。
- 确认无误后点击“上传”，再在版本管理中提交体验版。
- 根目录 `old/` 已在 `project.config.json` 的上传和监听配置中忽略，不会进入上传包；若包分析仍包含它，可暂时将 `old/` 移出项目目录。
- 如果上传仍提示超限，优先查看代码包大小分析中的具体目录，不要直接删除 `assets/game`；该目录是运行时分包。

微信存档通过 `wx.getStorageSync` / `wx.setStorageSync` 保存。

## 目录

```text
index.html          浏览器试玩入口
styles.css         浏览器展示外壳
game.js            微信小游戏适配入口
game.json          微信小游戏运行配置
project.config.json 微信开发者工具配置
src/data.js         职业、卡牌、星球、任务与飞船配置
src/game-core.js    共享游戏循环、战斗、界面与渲染
src/web.js          浏览器输入、存档与音频适配
```

## 资源发布说明

根目录 `old/` 只存放评审稿、旧版素材、备份、生成脚本和校验报告，已在微信开发者工具的上传与监听配置中忽略。发布前可直接移除整个 `old/` 文件夹；运行时代码不引用其中内容。

## 调参入口

- 职业基础生命、伤害、攻速和射程：`src/data.js` 中各职业的 `base`
- 卡牌文案与组合配方：`src/data.js` 中 `cards` / `evolutions`
- 任务目标强度与撤离时间：`src/game-core.js` 中 `createObjective` / `extraction.required`
- 敌人模板与刷怪压力：`src/game-core.js` 中 `spawnEnemy` / `updateSpawning`
- 经济价格：`src/data.js` 中 `shipModules.costs` 与职业 `unlock`

原型数值均为验证假设，尚未经过真实玩家的 8–10 分钟留存测试。
