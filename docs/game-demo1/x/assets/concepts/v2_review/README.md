# 《星际外勤》V2 视觉评审包

本目录只包含视觉评审素材，不参与当前游戏运行。

- `ui/`：360×640 逻辑稿与 720×1280 评审稿。
- `characters/`：角色正面透明图、方向与移动分镜。
- `enemies/`：三颗生态的敌人方向与移动分镜。
- `motion/`：最近邻放大的动画 GIF。
- `sources/`：GPT Image 2 生成的高分辨率母图与透明处理结果。
- `prompts/`：可复现的图像提示词。
- `music_direction.md`：背景音乐制作规格。

本轮不会修改 `src/`、`game.js`、`index.html` 或正式资源清单。
