# 背景音乐方向

## 驾驶舱 / HQ

- 速度：88 BPM，4/4拍，32小节无缝循环。
- 结构：8小节冷启动、16小节稳定巡航、8小节终端应答后回到循环点。
- 音色：方波琶音、低频模拟合成器持续音、短促终端脉冲、低音量舱体机械嗡鸣。
- 动态：保持低密度，不抢占按钮和广播音效；菜单停留超过16小节时只改变高八度装饰音。

## 星球探索

- 速度：104 BPM，4/4拍，32小节无缝循环。
- 基础层：稀疏鼓机、脉冲贝斯、两音动机和轻微噪声打击。
- 锈蚀荒原：失真金属敲击、磁暴噪声和橙红危险脉冲。
- 孢子沼泽：不稳定音高、湿润滤波噪声和低频孢子呼吸感。
- 低重力月面：空旷延迟、玻璃质方波和大间隔低音鼓。

## 撤离

- 速度：136 BPM，4/4拍，16小节无缝循环。
- 在探索层上增加十六分音符脉冲、上升音型、短促警报节奏和更强底鼓。
- 第13–16小节制造持续上升感，但循环回第1小节时保持和声连续。
- 成功、失败结算使用独立短音，不写入循环主体。

## 混音约束

- 音乐总响度低于主要武器和公司广播约6 dB。
- 同类敌人密集出现时，优先压低中高频音乐层而不是提升音效总音量。
- 三段音乐共享主旋律的四音公司动机，保证场景切换仍有统一身份。
