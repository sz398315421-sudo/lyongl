ER-6 // 工程图使用说明

这张实时工程图展示了一辆六轮探测车。它会扫描前方地形，根据自身越障能力规划路线，在各个勘测目标之间自主行驶。图中数据来自仿真参数和模型测量值。

进入沉浸模式后可继续旋转和缩放。轻点场景或按 Esc 即可退出。

试一试

  • 切换地形，观察车辆如何寻找坡道穿越河槽、顺着雅丹的脊线前进，或在崎岖的熔岩地上调节悬架。
  • 在沙丘上放飞侦察旋翼机，看它如何勘测前路。
  • 关闭激光雷达，把时间调至夜间，再打开泛光灯观察照明范围。
  • 启用太阳翼并关闭反应堆，观察车辆如何调整停靠方向，利用日照补充能量。
  • 收起散热翼，观察反应堆的输出功率如何变化。
